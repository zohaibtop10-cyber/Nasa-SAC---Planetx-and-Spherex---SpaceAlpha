# Live Sky: Project Rules (Antigravity Context)
Product: A public 3D web app tracking SPHEREx data.
Non-negotiables:
1. Every displayed number MUST have a label: measured, derived, or assumed.
2. All 3D models MUST be tagged "Illustrative".
3. NO claims of discovering Planet X.
4. The Web App reads static JSON only. The Python pipeline handles all NASA API fetching.
